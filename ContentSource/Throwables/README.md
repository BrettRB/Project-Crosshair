# Original throwable models

SM_Frag.obj and SM_Tomahawk.obj are project-authored centimeter-scale meshes generated by Scripts/create_throwable_models.py. The grenade uses a rounded body, fuse neck, spoon, pin and ring. The axe uses a tapered grip, curved beveled blade and metal grip rings. Crosshair.mtl names Paint, Metal, Rubber and Glass slots; Unreal imports resolve these to the project's existing weapon finish materials.

The Unreal assets live in Content/Crosshair/Weapons/Throwables. Regeneration runs through the Unreal Python commandlet and replaces only these two generated assets. Preserve artist replacements before regenerating. Collision and trajectory come from the gameplay sphere/projectile component rather than mesh collision.
