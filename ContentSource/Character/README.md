# Original tactical character gear

SM_ElbowPad.obj is original project geometry generated by Scripts/create_combat_character.py using the existing weapon geometry writer. Centimeter dimensions; semantic material slots use project finishes. Runtime pads attach to lower-arm bones through UCrosshairCombatAppearance and have no collision. The character retains the existing mannequin skeleton/animation with dedicated fabric/glove shading. Run the script with UnrealEditor-Cmd and an absolute Python script path; template assets are left untouched.


## Soldier target designs

Soldiers/ contains project-authored OBJ equipment generated by Scripts/create_soldier_appearances.py. Six catalog designs share the existing rig with new uniform materials, helmets/caps/boonie hat, carriers, goggles, headset, pack, pouches and knee armor. Mesh sources compensate for Unreal OBJ Y-axis conversion. See docs/soldier-appearances.md for runtime and future bot integration. Template skeletal assets are not modified.
