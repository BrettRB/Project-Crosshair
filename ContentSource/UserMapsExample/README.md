# Original runtime map example

Import map.json from the game Maps / Import section. This original fixture has a 20 m square floor, a backstop, a capsule-center spawn at (0,0,100), and a project-authored 4x4 checker PNG. Coordinates use centimeters, X forward and Z up. The invalid.json file is a deliberately rejected path-escape test, not a playable map.

See docs/home-classes-and-map-import.md for export conventions, supported formats and limits. These assets are copied into the local map library when imported; changes to these source files require another import.
